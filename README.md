# writing_spec

This repository provides writing specifications for agents.

## Invene Technical Writing Specification (ITWS)

`spec/` contains **ITWS 0.2.1-draft**. ITWS is a controlled-language specification for technical writing.

The specification combines a shared core with eight profiles. The profiles cover design proposals, decision records, procedures, explanations, incident reports, technical reports, research papers, and investigation logs.

The base reader is a working software engineer. Each profile adds only the genre knowledge that Annex B defines.

See [spec/README.md](spec/README.md) for the profile registry, conformance tiers, and contents.

Annex G records the Research Writing Specification (RWS) 0.1 lineage. This repository does not contain a checkable 0.1 snapshot.
